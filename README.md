# plus-automation:PLUS 土地利用模拟一站式技能包

**一句话说清**:装上这个技能包,你对 AI 说一句"帮我预测武汉市 2050 年土地利用图",回答几轮选择题,剩下的全自动完成——数据下载、因子准备、模型训练、未来模拟、精度报告、论文级出图,一步到位。

## 它解决什么问题

传统跑 PLUS 土地利用模型,要做一大堆琐碎又容易出错的事:找数据源、下载逐年土地利用图、准备十几项驱动因子、统一投影和网格、检查数据格式、逐个模块手动操作、整理结果出图……门槛高、耗时长。

这个技能把整条链**全部自动化**:

```
一句话指令 → 分轮确认参数 → 自动下载数据 → 自动准备因子 → 自动建模
→ 自动验证精度 → 自动出论文级图 → 一份完整报告
```

每一步都带质量检查:数据格式不符会拦住并自动修复,因子对不齐会自动重采样,建模出错会按官方手册排错,不会带着问题硬跑出假结果。

## 能给你什么

- **未来土地利用模拟图**(如 2050 年各地类分布,论文级 300dpi 成图,图例/比例尺/指北针齐全)
- **各地类面积统计**(每期每类多少平方公里,变化多少)
- **精度报告**(Kappa、FoM 双指标 + 误差分解,并用大白话解释数字含义)
- **完整可追溯的流程报告**(用了什么数据、什么参数、改了什么规则,全部落盘)

## 怎么用

1. 把技能包装进 Claude Code(或同类 AI 助手),推荐用 DeepSeek 系列大模型执行
2. 说一句话,如"帮我预测成都市 2050 年土地利用图"
3. 按弹窗选择题回答研究区、年份、数据源等几个问题
4. 等结果

## 核心特点

- **数据自动下载**:CLCD 30m 逐年土地利用(中国区域)、ESA WorldCover 10m(全球)、官方同款 17 项驱动因子,失败自动降级/兜底
- **模型官方原汁原味**:调用 PLUS 官方引擎计算,不改模型本体,结果与手动操作逐像素一致
- **先问再跑**:所有研究决策(年份、矩阵、水域锁定等)都由你选择,AI 只负责执行
- **诚实报告**:精度指标如实汇报,并区分"回测验证"与"未来预测"两种口径
- **可复现**:同配置重跑结果统计一致,过程全留档
