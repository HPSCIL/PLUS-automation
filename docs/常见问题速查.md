# PLUS 引擎常见问题速查(官方说明书索引)

> 来源:《教程一:plus模型原理和软件介绍 20250531.pdf》第 5 章"常见问题"(PDF 在本目录,章节含截图)。
> 用法:先按"报错码 / 现象"左列匹配 → 打开教程一对应小节看原文与配图 → 按右列要点处理。
> skill 自身流程的坑(断点 / 连续预测期数 / 报告模板 / 矩阵)不在这里,见包根目录 `FAQ.md`。

| 报错码 / 现象 | 说明书小节 | 处理要点(摘要,原文为准) |
|---|---|---|
| 打不开 PLUS 软件 | 5.1 | 安装 Visual C++ Redistributable for VS2015(x64;微软官网下载链接见原文) |
| LEAS 报 "make df-trees success=-1" / 无弹窗崩溃 | 5.2 | 驱动因子与扩张图行列/坐标系不一致:先只喂 1 个因子看能否跑通,再逐个加因子定位问题因子;用 GIS 统一所有因子与扩张图的行列号、坐标系、投影 |
| LEAS 弹窗崩溃("预测请稍候……") | 5.3 | 数据量超过内存:降低分辨率,或换 64G/128G 内存的机器 |
| 概率图/模拟结果出现随机噪声点 | 5.4 | LEAS 模块线程数设为 1 重跑,把新的概率波段再交给 CARS 重跑 |
| 模拟结果出现无数据空洞 | 5.5 | 驱动因子里存在无数据区:剔除带 nodata 的驱动因子 |
| Markov 输出 NaN | 5.6 | 两期分类号必须是连续整数且行列一致(本 skill 已自动校验编码连续性 + 起始年 0 像元类自动归并) |
| 某类数量总是达不到设定需求 | 5.7 | ①检查概率波段正常非空 ②需求量与起始量同数量级 ③调参:邻域调大(11、21)、斑块生成阈值调低、扩张系数调大;复杂情形用两阶段模拟(原文有完整示例) |
| **CARS 崩溃 0xC0000005** / 扩张图缺某类 | **5.8** | **LEAS 按扩张图最大类别编码决定波段数;末位类从未扩张 → 波段少 1 → CARS 类别数不匹配崩溃。解法:重编码把"有扩张的类"放末位,重跑扩张提取(或保证末位类有少量转入斑块)。skill 已自动检测,处理细节见 FAQ.md F2** |

## 补充说明

- **5.6 / 5.8 两类问题 skill 已内置自动防护**(编码连续性检查、0 像元类自动归并、扩张图缺类检测);命中时管线会直接打印中文报错并指回本表,不会带着问题硬跑。
- 其余条目(5.1~5.5、5.7)是引擎/数据层面的问题,skill 无法自动修复,按上表人工处理。
- 本目录三份 PDF:`教程一`(用户手册,含常见问题章)、`教程二`(规划政策 policy 栅格教程)、`plus模型原理和软件介绍-v3`(旧版介绍,作方法参考)。
